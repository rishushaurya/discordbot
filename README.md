# lilgooner Discord Bot

Lilgooner is a fun, cringe-inducing, Gen-Z slang-heavy Discord bot with active trolling systems (ghost, puppet, chaos, mute), and a dual AI backend supporting normal Groq chat and uncensored, database-persisted obsessed-girlfriend roleplay via OpenRouter.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a `.env` file in the root directory:
   ```env
   DISCORD_TOKEN=your_discord_bot_token
   GROQ_API_KEY=your_groq_api_key
   OPENROUTER_API_KEY=your_openrouter_api_key
   ```
3. Start the bot:
   ```bash
   npm start
   ```
